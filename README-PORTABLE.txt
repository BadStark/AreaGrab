AreaGrab 1.1 — portable build

1. Extract this folder anywhere you can write (Desktop, Documents, USB drive).
2. Run AreaGrab.exe.
3. Settings, logs and the default screenshots folder are stored in .\data.
4. Press PrtScr, select an area, release. The image is in your clipboard; press Ctrl+V.

No installer, no admin rights, no registry entries, no Start Menu shortcuts.

To uninstall: exit AreaGrab from the tray, then delete this folder.

If you want the normal per-user installation with Start Menu shortcuts and
uninstaller, use AreaGrab_Setup_1.1.0.exe instead.

In the Portable Pro Preview, double-click AreaGrab.exe to test local sharing.
Exit any running AreaGrab instance first. Capture an image and choose
Send to device in the notification, main tray menu, or tray history.
