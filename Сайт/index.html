Questions

Does PrtScr open Snipping Tool too?

AreaGrab suppresses PrtScr while it is running, so Snipping Tool should not open. If it does, Settings → Capture has a one-click fix for the Windows setting and an option to choose another hotkey.

Do I need administrator rights?

No for normal use. AreaGrab installs per-user and does not request UAC. Capturing over a window that itself runs as administrator requires running AreaGrab as administrator — that is an optional limitation of Windows, not a requirement.

Where are my screenshots saved?

By default in Pictures\Screenshots. You can choose any folder in Settings → Saving. The toast after each capture shows the file name and folder.

How do I stop creating files?

Uncheck “Save to folder” in Settings → Saving. The screenshot stays in the clipboard and in the in-memory history only. No file is written.

How do I paste a screenshot?

After capture, open Telegram, Slack, Gmail, Word, Figma or any app that accepts images and press Ctrl+V. On Windows you can also use Win+V clipboard history if it is enabled.

Why does Windows SmartScreen warn me?

AreaGrab 1.1 is not code-signed yet, so Windows may show “Unknown publisher”. The installer is built from this project; the SHA-256 is published below. A signed build is planned.

Is there a Pro version?

Pro is in development. Join the waitlist and you will get the launch price. The free version stays useful — clipboard, folder and no-save mode will not be paywalled.
